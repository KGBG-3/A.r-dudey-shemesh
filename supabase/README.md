# מערכת העבודות של א.ר דודי שמש

יומן העבודות של משה ואבא, במקום היומן בגוגל (שממשיך לקבל העתק של כל עבודה).

- `admin/` מסך הניהול: ardudim.co.il/admin. כניסה נפרדת למשה ולאבא. יומן לפי ימים, בקשות מהאתר, "מחר" עם תזכורות בוואטסאפ, הדבקת הודעת תיאום של כרומגן, ימי חופש, אזורים, נוסחי הודעות, התראות לטלפון והעתק ליומן גוגל. אפשר להוסיף למסך הבית כמו אפליקציה.
- הכרטיס "רוצים לקבוע מועד?" במחשבון (`index.html`, `#ardudim-booking-js`): הלקוח בוחר יישוב, עד 3 ימים וחלק ביום, והבקשה נשמרת כאן ונשלחת גם בוואטסאפ.
- `assets/jobs-config.js` הכתובת של הפרויקט ב-Supabase והמפתח הציבורי שלו (מותר שיהיה ציבורי).
- `supabase/schema.sql` מבנה המסד והכללים. רק משה ואבא (בטבלה `admins`) קוראים ומשנים. מבקרים באתר יכולים רק לשלוח בקשה (`request_job`) ולראות אילו ימים פתוחים (`public_days`, בלי פרטים אישיים).
- `supabase/functions/notify/` פונקציית השרת: התראה לטלפון על כל בקשה מהאתר, רשימת העבודות של מחר בערב, והעתק של כל עבודה ליומן "עבודות דודים" בגוגל.
- `admin/gcal-script.txt` הקוד שרץ בחשבון הגוגל ומעדכן את היומן. מסך הניהול מעתיק אותו עם הסיסמה שלו (הגדרות ← העתק ליומן גוגל).

## הקמה (פעם אחת)

1. ב-Supabase: פרויקט חדש (אזור Frankfurt).
2. Authentication ← Users ← Add user: `moshe@ardudim.co.il` ו-`iliya@ardudim.co.il`, עם סיסמה ו-Auto Confirm User. אלה רק שמות כניסה, בלי תיבת מייל.
3. Authentication ← Sign In / Providers: מכבים את Allow new users to sign up, כדי שאף אחד אחר לא יוכל לפתוח משתמש.
4. SQL Editor: מדביקים את כל `supabase/schema.sql` ומריצים. (מריצים שוב אם מוסיפים משתמש אחר כך.)
5. Edge Functions ← Deploy a new function ← Via Editor: השם `notify`, מדביקים את `supabase/functions/notify/index.ts`, ובהגדרות של הפונקציה מכבים את Verify JWT.
6. נכנסים ל-ardudim.co.il/admin, מוסיפים למסך הבית, ובהגדרות מפעילים התראות (בכל טלפון, גם של אבא).
7. מהמחשב: הגדרות ← העתק ליומן גוגל, ולפי השלבים שם.

## כללים

- פרטים של לקוחות לא נכנסים לריפו (הוא ציבורי). רק קוד.
- עבודה שכבר הועתקה ליומן גוגל מבטלים, לא מוחקים, כדי שתימחק גם מהיומן.
